A free make.fun bounty entry for **the-joke-about-the-demo-20261121-0551**
("The joke about the demo"). It is a single one-line joke about working
beside an AI coding agent — told from the stage of a live demo, in front of
a watching room, where the agent's "tiny fix" takes the whole site down
mid-sentence and the audience mistakes the crash for the feature.

## Run

```sh
python3 main.py
```

The joke is written to `/output/entry.txt` (the directory is created if
missing). Python 3.13, standard library only, no network access, and fully
deterministic — two runs produce byte-identical output.
